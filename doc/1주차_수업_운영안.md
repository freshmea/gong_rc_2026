# 1주차 수업 운영안

---

교육 기간은 2026년 6월 22일부터 6월 26일까지이다. 목표는 수강생이 WSL, VS Code, Git 환경에 적응하고 AutoCar 실습에 필요한 Python 기초와 프로그램 구조를 익히는 것이다.

## 주간 목표

---

- WSL 경로에서 VS Code와 Git을 사용해 실습 파일을 관리한다.
- 조건문, 반복문, 컬렉션, 함수, 파일 입출력을 사용한다.
- 클래스, 모듈, 예외 처리로 프로그램을 구조화한다.
- `pywebview`, Flask, 스레드와 비동기 처리의 역할을 구분한다.

## 차시 운영

---

### Day 1. 개발 환경과 Python 첫 실행 - 6월 22일

- 핵심 주제: 오리엔테이션, WSL2, VS Code, Git/GitHub, 출력, 변수, 자료형, 연산자, 입력, 문자열 포매팅
- 실습 자료: `doc/WSL(windows_subsystem_for_linux) 안내자료.pdf`, `python/a01_hello.py`, `a04_print.py`, `a05_type.py`, `a08_operator.py`, `a11_input.py`, `a13_formatting.py`
- 실습 산출물: 입력값을 계산해 형식에 맞춰 출력하는 프로그램
- 확인 질문: 현재 파일이 WSL 경로인지 설명할 수 있는가, 커밋과 원격 저장소의 역할을 구분하는가

### Day 2. 조건문, 컬렉션, 반복과 UI - 6월 23일

- 핵심 주제: `if/elif/else`, 리스트, `for`, `range`, `enumerate`, `zip`, GitHub Pages, `pywebview`
- 실습 자료: `python/a15_comparison_operator.py`, `a20_odd_elif.py`~`a24_range_enumerate.py`, `a26_webview.py`, `python/text.html`, `index.html`
- 실습 산출물: 리스트 데이터를 분류해 웹뷰에 표시하는 프로그램
- 확인 질문: 거짓으로 평가되는 값은 무엇인가, Python과 HTML은 웹뷰에서 어떻게 연결되는가

### Day 3. 함수, 파일, 반복 가능한 처리 - 6월 24일

- 핵심 주제: `while`, 함수와 인자, 재귀, 람다, 파일 입출력, 제너레이터, 클로저, 데코레이터, 예외
- 실습 자료: `python/a27_while_loop.py`~`a40_lambda_basic.py`, `a42_file_write.py`~`a45_iterable.py`, `a101_wrapper_function.py`~`a103_time_decorator.py`, `a47_try_except.py`, `a54_exception_custom.py`
- 실습 산출물: 파일 데이터를 함수로 처리하고 실행 시간을 기록하는 프로그램
- 확인 질문: 반환과 출력은 어떻게 다른가, `with open(...)`과 예외 처리는 왜 필요한가

### Day 4. 객체와 데이터 저장 - 6월 25일

- 핵심 주제: `pickle`, 딕셔너리, 클래스, 특수 메서드, 클래스 변수/메서드, 프로퍼티, 상속
- 실습 자료: `python/a96_pickle_file.py`, `a97_pickle_load.py`, `a61_class_dictionary.py`~`a72_multiple_inheritance.py`, `data/student_info.json`, `data/student_info.data`
- 실습 산출물: 학생 정보를 객체로 관리하고 저장·복원하는 프로그램
- 확인 질문: 딕셔너리와 클래스는 어떻게 다른가, 저장 객체를 다시 읽을 때 클래스 정의가 왜 필요한가

### Day 5. 패키지, 동시성, 미니 프로젝트 - 6월 26일

- 핵심 주제: `sys`, `os`, 패키지, `uv`, `pywebview`, `threading`, `asyncio`, Flask, SSE
- 실습 자료: `python/a104_sys.py`~`a106_url.py`, `python/test_package/`, `a90_package_import.py`, `a73_frame.py`, `a104_multithreading.py`, `a105_asyncio_tasks.py`, `uv_test/`
- 실습 산출물: Flask 데이터를 웹뷰 UI에 표시하는 미니 프로그램
- 확인 질문: 가상환경은 왜 필요한가, 서버·UI·데이터 처리를 분리하면 무엇이 좋은가

---
